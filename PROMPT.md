## The project

This will be a 2D game engine written in Rust. The focus of this engine is optimization. Initially it will be used for incremental game math, and should be optimized to be capable of running complex sims in game. It will eventually also be used to create high-performance multiplayer games and a 2d game that requires a heavily optimized and ultra powerful destruction engine.

The destruction game is far down the road, so the first versions of this engine do not need a full destruction engine, but should have the 'groundwork' done such that what is needed can be built on top.

This engine should be built with AI use in mind and an in-depth MCP should be kept up-to-date.

## Features

-The engine must have easy to edit UI elements and features.
-The engine must use an ECS.
-The engine must have a very easy to navigate heirarchy.
-Data must be stored in custom serialized formats that are incredibly efficient.
-The engine must have a feature similar to scriptable objects.
-The engine must support top-down, sidescroller and isometric 2d games.
-The engine must have custom support for pixel art assets and rendering.
